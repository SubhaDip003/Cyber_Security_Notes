## Tactics, Techniques & Procedures [TTP]

**<span style="color: red;">Tactics</span>** describe what an attacker wants to achieve.
**<span style="color: red;">Techniques</span>** explain how they achieve it.
**<span style="color: red;">Procedures</span>** describe the specific steps used to carry out the attack.
